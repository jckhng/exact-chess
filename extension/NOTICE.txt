Exact Chess
===============

Unofficial e-ink-friendly chess derived from GNOME Chess rules and artwork,
with optional Stockfish play.

This package includes:
- the Exact Chess application binary
- launcher scripts for KUAL
- a bundled ARM runtime library set for GTK2/Cairo/RSVG/X11
- SVG piece themes derived from GNOME Chess
- GPL license texts from the source tree

Project lineage
---------------

Exact Chess is an unofficial derivative adaptation based in part on GNOME
Chess and GNOME Games code and assets. It reuses and adapts chess rules logic
and visual assets from the upstream GNOME Games codebase for jailbroken
KUAL-capable e-ink reader devices.

This work also benefited from prior GNOME Games e-ink/KUAL porting and
packaging work by ThatPotatoDev and contributors. Original GNOME Chess code
and artwork remain credited to the GNOME Games authors.

This package is not an official GNOME project and is not affiliated with or
endorsed by GNOME, the GNOME Foundation, device manufacturers, or the prior
e-ink/KUAL porting projects it credits.

Runtime library note
--------------------

To reduce external dependencies on the e-ink reader, this package can bundle the
ARM shared-library runtime needed by the app. Those libraries are third-party
components from the build environment and remain under their own licenses.

See:
- LICENSES/RUNTIME-LIBS.txt for the bundled library list
- LICENSES/THIRD-PARTY-NOTICE.txt for packaging notes

Engine note
-----------

This package does not bundle a Stockfish engine binary from this repository
unless one is explicitly supplied to the packager. The launcher will:

1. use /mnt/us/extensions/exact-chess/bin/armhf/stockfish if you add one
2. otherwise fall back to the stockfish wrapper/binary from gnomegames if present

So the package is immediately usable as:
- 2-player chess
- engine chess if a compatible Stockfish binary is available
